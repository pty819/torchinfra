## 结论: 未达 1.3x (86s) 线 → Phase B 放行

归因: fp8 GEMM 收益被 eager 胶水抵消——每步 5.94s 中 norm/rope fp32 转换、
逐层激活量化、python 循环、bf16 SDPA 估计占 40-50%。

## Phase B 补差清单 (按性价比)

1. 受限 torch.compile (TORCHINDUCTOR_COMPILE_THREADS=2) — 融合胶水, 预期 -15~30%
   ⚠️ 11-19 unrestricted compile 致 RAM 压穿系统锁死, 必须限线程
2. Triton 胶水融合 (RMSNorm+调制+残差 / rope) — 预期 -10~15%
3. FlyDSL FP8 attention (P16 骨架改 DiT 头布局) — 预期 -20~30%
4. er_sde 移植 + Qwen3-VL 编码器接入 (画质对拍)
